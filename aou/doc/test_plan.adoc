[[aou-core-test-plan]]
===== Test Plan

====== Standalone bench

`test/aou_core_tb.cpp` uses two `aou_core` instances with
`connect_peer`, FDI tied high, and a peer memory on B.

Success: the bench prints `ALL TESTS PASSED`; `--asan` produces no
`asan.log.*` when a 64-bit libasan is available; line coverage on
`aou_core.cpp` meets the repository ≥ 95% gate.

How to run (from `aou`):

[source,bash]
----
cp deps.env.example deps.env   # first time; set SYSTEMC_HOME / CCI_HOME
./run_tests.sh
./run_tests.sh --asan
./run_tests.sh --coverage   # do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean
----

RHEL 8 toolset packages may lack 64-bit libasan; Ubuntu CI still runs
`--asan`.
