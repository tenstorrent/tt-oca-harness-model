[[local-master-alias-remap-ctrl-test-plan]]
===== Test Plan

====== Standalone bench

`local_master_alias_remap_ctrl_testbench` is a TLM CSR initiator, a
data-path initiator, and a stub on `remapped_socket`.

Success: every `[PASS]` report holds; `--asan` produces no
`asan.log.*`; line coverage on the touched model sources meets the
repository ≥ 95% gate.

How to run (from `sep/peripherals/local_master_alias_remap_ctrl`):

[source,bash]
----
./run_tests.sh              # Release build + run
./run_tests.sh --debug
./run_tests.sh --asan       # ASan + UBSan
./run_tests.sh --coverage   # isolated build/coverage; do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

# All SEP peripherals, this IP included:
cd sep/peripherals
./run_all_peripherals.sh
./run_all_peripherals.sh --clean local_master_alias_remap_ctrl
----

`run_tests.sh` loads `SYSTEMC_HOME` / `CCI_HOME` through
`sep/peripherals/setup_build_env.sh`. Set those in `vp/configure_vp.sh`
or export them first.

====== Standalone cases

Source: `test/src/local_master_alias_remap_ctrl_testbench.cpp`.

[cols="8%,36%,40%,16%",options="header"]
|===
|ID |Name |What the model test proves |Type
|T1 |Reset |All regions 0 / invalid |Positive
|T2 |Region 0 program |START / END / ATTRS readback |Positive
|T3 |Hit remap |Additive offset |Positive
|T4 |Miss passthrough |Addr unchanged |Positive
|T5 |First-match |Region 0 beats later overlap |Positive
|T6 |Low 12 bits kept |Page offset preserved |Positive
|T7 |WRITE remap |Same as READ |Positive
|T8 |Address restored |Caller payload unchanged |Positive
|T9 |transport_dbg |Same remap |Positive
|T10 |Field masks |Reserved bits discarded (entries 0 / 7 / 15) |Mixed
|T10b |Cacheable field |4-bit `cacheable[59:56]` round-trips; bit 62 reserved;
RW mask `0x8FFFFFFFFFFFF000` |Positive
|T11 |rst_ni |Clears the table; former hit becomes passthrough |Positive
|T12–T17 |cacheable override |Bit-for-bit AxCACHE replacement (0x6 / 0x0 / 0x9)
on hit; miss passthrough; restore; dbg |Positive
|T17b |No extension on hit |Remapped with no AxCACHE to override |Positive
|T18 |get_region guard |Out-of-range index |Negative
|T19 |Partial CSR writes |32-bit and byte-enable lanes merge, disabled lanes
kept |Mixed
|T20 |Malformed CSR payloads |Bad length / command / streaming width / null
data pointer; entry left unchanged |Negative
|T21 |Range oracle |`start`, `end-1`, `end`; empty and reversed ranges |Mixed
|T22 |Offset overflow |44-bit wrap with the low 12 bits preserved |Negative
|T23 |Overlap priority |First match wins across an invalidate cascade, proven
by the winning entry's distinct `cacheable` nibble |Mixed
|T24 |Extension handling |Absent extension, field preserve, restore on error
|Mixed
|T25 |Annotated delay |Downstream +17 ns accumulated, metadata intact |Positive
|T26 |transport_dbg miss |Byte count and passthrough on no match |Mixed
|===

CSR helpers return the TLM response status and are `[[nodiscard]]`: a
rejected transaction that went unchecked would otherwise pass silently on
stale buffer contents.

====== Platform firmware tests

These run on `sep-vp` with a RISC-V bare-metal toolchain. Build the VP
first (`make sep-vp` from the repo root after `vp/configure_vp.sh`).

[source,bash]
----
cd sw/sep-vp-tests/fw-tests-from-tt-oca-hw/fw/sep
./run_test.sh local_alias_sanity
./run_all_tests.sh            # full firmware suite
----

`fabric_local_alias_*` and `global_alias_remap_sanity` are excluded
from the VP suite (upstream compile or testbench mismatch).
