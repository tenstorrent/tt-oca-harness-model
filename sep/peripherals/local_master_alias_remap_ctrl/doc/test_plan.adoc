[[local-master-alias-remap-ctrl-test-plan]]
===== Test Plan

====== Standalone bench

`local_master_alias_remap_ctrl_testbench` is a TLM CSR initiator, a
data-path initiator, and a stub on `remapped_socket`.

Success: every `[PASS]` report holds; `--asan` produces no
`asan.log.*`; line coverage on the touched model sources meets the
repository ≥ 95% gate.

How to run (from `sep/peripherals/local_master_alias_remap_ctrl`):

[source,bash]
----
./run_tests.sh              # Release build + run
./run_tests.sh --debug
./run_tests.sh --asan       # ASan + UBSan
./run_tests.sh --coverage   # isolated build/coverage; do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

# All SEP peripherals, this IP included:
cd sep/peripherals
./run_all_peripherals.sh
./run_all_peripherals.sh --clean local_master_alias_remap_ctrl
----

`run_tests.sh` loads `SYSTEMC_HOME` / `CCI_HOME` through
`sep/peripherals/setup_build_env.sh`. Set those in `vp/configure_vp.sh`
or export them first.

====== Platform firmware tests

These run on `sep-vp` with a RISC-V bare-metal toolchain. Build the VP
first (`make sep-vp` from the repo root after `vp/configure_vp.sh`).

[source,bash]
----
cd sw/sep-vp-tests/fw-tests-from-tt-oca-hw/fw/sep
./run_test.sh local_alias_sanity
./run_all_tests.sh            # full firmware suite
----

`fabric_local_alias_*` and `global_alias_remap_sanity` are excluded
from the VP suite (upstream compile or testbench mismatch).
