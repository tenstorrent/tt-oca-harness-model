[[lifecycle-ctrl-test-plan]]
===== Test Plan

====== Standalone bench

`lifecycle_ctrl_testbench` (`test/inc/testbench.h`) is a TLM
initiator into `target_socket`. Tests 1–12 read `FEAT_CTRL` as
CCI left it; 4 / 8 / 9 / 12 skip unless the ini matches.
Tests 13–21 call `set_inputs()` so every state arm runs in one
invocation.

Success: every `report_test_pass` in `test/src/testbench.cpp`
holds; `--asan` produces no `asan.log.*`; line coverage on the
touched model sources meets the repository ≥ 95% gate.

How to run (from `sep/peripherals/lifecycle_ctrl`):

[source,bash]
----
./run_tests.sh              # Release build + run
./run_tests.sh --debug
./run_tests.sh --asan       # ASan + UBSan
./run_tests.sh --coverage   # isolated build/coverage; do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --docs
./run_tests.sh --cppcheck
./run_tests.sh --clean
./run_tests.sh --no-build   # re-run only

# All SEP peripherals, this IP included:
cd sep/peripherals
./run_all_peripherals.sh
./run_all_peripherals.sh --clean lifecycle_ctrl
----

`run_tests.sh` loads `SYSTEMC_HOME` / `CCI_HOME` through
`sep/peripherals/setup_build_env.sh`. Set those in
`vp/configure_vp.sh` or export them first.

====== Platform firmware tests

These run on `sep-vp` with a RISC-V bare-metal toolchain. Build
the VP first (`make sep-vp` from the repo root after
`vp/configure_vp.sh`).

[source,bash]
----
cd sw/sep-vp-tests/fw-tests-from-tt-oca-hw/fw/sep
./run_all_tests.sh            # full firmware suite
----

`lcc_inbound_filter_gating_test` waits on an external AXI UVM
master that `sep-vp` does not provide. Demote and `sep_debug`
are covered indirectly by boot and filter behaviour on other
tests.
