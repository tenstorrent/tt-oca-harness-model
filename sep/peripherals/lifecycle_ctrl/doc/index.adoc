==== Lifecycle Controller

The hardware contract (lifecycle encodings, `FEAT_CTRL` vector, demote
registers) is in the hardware TRM. This directory documents the
SystemC/TLM-2.0 model (`lifecycle_ctrl_model`) and how to test it.
