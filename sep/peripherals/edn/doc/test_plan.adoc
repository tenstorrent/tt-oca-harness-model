===== Test Plan

====== Standalone bench

`edn_test` (`test/inc/edn_test.h`) is a TLM initiator into the register
aperture plus `clk_i` / `rst_ni` and interrupt / alert monitors. CSRNG
and endpoint behaviour is mocked inside the harness (`m_entropy_buffer`),
not bound as DUT sockets. The DUT is `edn_ip`.

Success: every check in the EDN_FUNC suites passes; `--asan` produces no
`asan.log.*`; line coverage on the touched model sources meets the
repository ≥ 95% gate.

How to run (from `sep/peripherals/edn`):

[source,bash]
----
./run_tests.sh              # Release build + run
./run_tests.sh --debug
./run_tests.sh --asan       # ASan + UBSan
./run_tests.sh --coverage   # isolated build/coverage; do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

# All SEP peripherals, this IP included:
cd sep/peripherals
./run_all_peripherals.sh
./run_all_peripherals.sh --clean edn
----

`run_tests.sh` loads `SYSTEMC_HOME` / `CCI_HOME` through
`sep/peripherals/setup_build_env.sh`. Set those in `vp/configure_vp.sh`
or export them first.

====== Platform firmware tests

These run on `sep-vp` with a RISC-V bare-metal toolchain. Build the VP
first (`make sep-vp` from the repo root after `vp/configure_vp.sh`).

Native suite (`sw/sep-vp-tests`):

[source,bash]
----
cd sw/sep-vp-tests
./run_sep_vp_tests.sh sep-edn-test
----

The hardware-tree firmware set under
`sw/sep-vp-tests/fw-tests-from-tt-oca-hw/fw/sep` has no EDN-named tests.
