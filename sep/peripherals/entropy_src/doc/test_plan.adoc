[[entropy-src-test-plan]]
===== Test Plan

====== Standalone bench

The standalone bench (`test/inc/testbench.h`) is a TLM initiator into
the register aperture plus `rst_ni` and an `irq_o` monitor. The DUT is
`entropy_src_ip`.

Success: every check in the FUNC suites passes; `--asan` produces no
`asan.log.*`; line coverage on the touched model sources meets the
repository ≥ 95% gate.

How to run (from `sep/peripherals/entropy_src`):

[source,bash]
----
./run_tests.sh              # Release build + run
./run_tests.sh --debug
./run_tests.sh --asan       # ASan + UBSan
./run_tests.sh --coverage   # isolated build/coverage; do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

# All SEP peripherals, this IP included:
cd sep/peripherals
./run_all_peripherals.sh
./run_all_peripherals.sh --clean entropy_src
----

`run_tests.sh` loads `SYSTEMC_HOME` / `CCI_HOME` through
`sep/peripherals/setup_build_env.sh`. Set those in `vp/configure_vp.sh`
or export them first.

====== Standalone cases

Sources: `test/src/func001_tests.cpp` … `func008_tests.cpp`,
`test_coverage.cpp`.

[cols="12%,28%,44%,16%",options="header"]
|===
|ID |Name |What the model test proves |Type
|FUNC-001 |TLM register transport |RO/RW/WO masks, identity |Positive
|FUNC-002 |Interrupts |W1C, INTR_TEST, `irq_o` |Mixed
|FUNC-003 |Config retention |Oscillator / decorrelator CSRs |Positive
|FUNC-004 |Background fill |FIFO enable, downsample, startup delay |Positive
|FUNC-005 |Health-test CSRs |Enable and status (stubbed tests) |Positive
|FUNC-006 |FIFO queue |Push / pop / overflow / underflow |Mixed
|FUNC-007 |Reset |rst_ni (TRNG domain) sequence |Positive
|FUNC-008 |Added RDL regs |Reset and access on extra words |Positive
|COV |Directed coverage (`test_coverage.cpp`) |Error and boundary paths the
FUNC suites do not reach: TLM protocol matrix (bad length / streaming width /
byte enables / `transport_dbg` / DMI), `STARTUP_CTRL` reserved-field RAZ/WI,
`entropy_export` with a short FIFO and during reset, and reset while the
generation thread is mid-wait |Negative

|===

A handful of lines stay outside the suite's reach and are marked
`LCOV_EXCL_BR_LINE` / `LCOV_EXCL_LINE` with a comment naming the invariant:
the `RAND_bytes()` failure path (an OpenSSL CSPRNG failure cannot be forced
from a bench) and the `entropy_generation_thread` epilogue it guards. Those
are the only exclusions; the defensive checks themselves are kept, not
deleted.

`sw/sep-vp-tests` nor `fw-tests-from-tt-oca-hw/fw/sep` lists an
entropy-source-named test. Register access is covered by the standalone
bench above.
