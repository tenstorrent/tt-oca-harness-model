[[sep-memory]]
==== SEP Memory

The hardware contract (SRAM / ROM / ITCM / DTCM apertures) is in the
hardware TRM. This directory documents the SystemC/TLM-2.0 store
(`SEPMemory`) and how to build it. Sources live under `model/`, not
`include/`.
