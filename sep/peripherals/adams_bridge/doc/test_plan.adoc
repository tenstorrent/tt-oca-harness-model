[[adams-bridge-test-plan]]
===== Test Plan

====== Standalone bench

`abr_testbench` (`test/inc/abr_testbench.h`) is a TLM initiator into
the register aperture, a second initiator into `keymgr_tl_socket`, KM
share initiators into `keymgr_*_socket`, plus `clk_i` / `rst_ni` and
`run_mldsa` / `run_mlkem` / `zeroize_*` helpers.

The default backend is `abr_fips_backend`. Tests that only need the
FSM may install `abr_shake_backend` through `set_crypto_backend()`.

Success: every `tb.check` / `tb.check_eq` in the four suites passes;
`--asan` produces no `asan.log.*`; line coverage on the touched model
sources meets the repository ≥ 95% gate.

How to run (from `sep/peripherals/adams_bridge`):

[source,bash]
----
./run_tests.sh              # Release build + run
./run_tests.sh --debug
./run_tests.sh --asan       # ASan + UBSan
./run_tests.sh --coverage   # isolated build/coverage; do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

# All SEP peripherals, this IP included:
cd sep/peripherals
./run_all_peripherals.sh
./run_all_peripherals.sh --clean adams_bridge
----

`run_tests.sh` loads `SYSTEMC_HOME` / `CCI_HOME` through
`sep/peripherals/setup_build_env.sh`. Set those in `vp/configure_vp.sh`
or export them first.

====== Standalone cases

Sources: `test/src/register_tests.cpp`, `mldsa_tests.cpp`,
`mlkem_tests.cpp`, `interrupt_kv_tests.cpp`, `nist_kat_tests.cpp`,

|6–21 |ML-DSA command / modifier / error / reset |Engine thread, park-on-VALID, zeroize |Mixed

====== Platform firmware tests

These run on `sep-vp` with a RISC-V bare-metal toolchain. Build the VP
first (`make sep-vp` from the repo root after `vp/configure_vp.sh`).

[source,bash]
----
cd sw/sep-vp-tests/fw-tests-from-tt-oca-hw/fw/sep
./run_test.sh sep_abr_csr_test
./run_test.sh sep_abr_keygen_test
./run_test.sh sep_abr_keygen_sign_test
./run_test.sh sep_abr_kat_test
./run_test.sh sep_abr_nist_kat_test
./run_test.sh sep_abr_km_seed_test
./run_all_tests.sh            # full firmware suite, includes the above
----

`sep_abr_nist_kat_test` needs the FIPS backend (the `sep-vp` default).
`sep_abr_km_seed_test` uses the KM ML-DSA seed socket bound from
`key_manager_model`.
