==== Adams Bridge

The hardware contract (aperture, CSRs, ML-DSA / ML-KEM commands, Key
Vault, interrupts) is in the hardware TRM. This directory documents
the SystemC/TLM-2.0 model (`abr_ip`) and how to test it.
