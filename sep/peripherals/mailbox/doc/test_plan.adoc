[[mailbox-test-plan]]
===== Test Plan

====== Standalone bench

`mailbox_testbench` (`test/inc/testbench.h`) is a pair of TLM
initiators into `socket0` / `socket1`, plus `clk_i` / `rst_ni`
and both `irq_o` pins. Helpers issue 32- and 64-bit register
accesses. A second DUT, `mailbox_unit_t<2>`, is instantiated
alongside with its own initiator, reset, clock and four
interrupt pins, so the wrapper's decode is exercised through
the bus rather than bypassed.

Success: every check in the seven func files passes; `--asan`
produces no `asan.log.*`; line coverage on the touched model
sources meets the repository ≥ 95% gate.

How to run (from `sep/peripherals/mailbox`):

[source,bash]
----
./run_tests.sh              # Release build + run
./run_tests.sh --debug
./run_tests.sh --asan       # ASan + UBSan
./run_tests.sh --coverage   # isolated build/coverage; do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --docs
./run_tests.sh --cppcheck
./run_tests.sh --clean

# All SEP peripherals, this IP included:
cd sep/peripherals
./run_all_peripherals.sh
./run_all_peripherals.sh --clean mailbox
----

`run_tests.sh` loads `SYSTEMC_HOME` / `CCI_HOME` through
`sep/peripherals/setup_build_env.sh`. Set those in
`vp/configure_vp.sh` or export them first.

====== Standalone cases

Sources: `test/src/testbench.cpp`, `test_mailbox_func001.cpp` …
`test_mailbox_func007.cpp`, `test_mailbox_unit.cpp` (~54 cases).
Names are the `test_*` methods.

[cols="8%,36%,40%,16%",options="header"]
|===
|ID |Name |What the model test proves |Type
|1–5 |Basic register |Reset, RO/WO/RW, async reset |Mixed
|6 |FUNC-001 reset |FIFOs and IRQs clear |Positive
|7–10 |FUNC-002 callbacks |IRQS W1C, IRQEN, threshold saturate |Positive
|11–22 |FUNC-003 FIFO |Both directions, occupancy edges, measured depth, STATUS coherence |Positive
|23–26 |FUNC-004 STATUS |Empty, full, both threshold flags |Positive
|27–32 |FUNC-005 errors |Write-to-full, read-from-empty, COR, EIRQ |Negative
|33–45 |FUNC-006 IRQ |WTIRQ/RTIRQ both ports, zero/max threshold |Mixed
|46–48 |FUNC-007 flush |Write/read flush, dual-port OR |Positive
|49 |Malformed payloads |Every generic-payload defect decided, both sockets |Negative
|50–54 |mailbox_unit_t |Block decode, routing, address restoration, holes and
aperture end, channel independence, reset fan-out, interrupt vectors |Mixed
|===

====== Platform firmware tests

These run on `sep-vp` with a RISC-V bare-metal toolchain. Build
the VP first (`make sep-vp` from the repo root after
`vp/configure_vp.sh`).

[source,bash]
----
cd sw/sep-vp-tests/fw-tests-from-tt-oca-hw/fw/sep
./run_test.sh sep_mailbox_plic_test
./run_test.sh sep_smc_mbox_irq
./run_all_tests.sh            # full firmware suite, includes the above
----

`sep_mailbox_plic_test` hits PIC sources for `irq_o[0]`.
`sep_smc_mbox_irq` is the SEP half of a two-chiplet handshake.
