[[otbn]]
==== OTBN

The hardware contract (aperture, CSRs, IMEM / DMEM, commands, Key Vault
sideload, interrupts) is in the hardware TRM. This directory documents
the SystemC/TLM-2.0 model (`otbn_ip`) and how to test it.
