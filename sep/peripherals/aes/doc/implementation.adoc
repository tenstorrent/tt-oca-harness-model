[[aes-implementation]]
===== SystemC/TLM-2.0 Implementation

`aes_model` is a loosely-timed TLM-2.0 model. Timing is quantum-keeper
cycle counts, not a cycle-accurate datapath. The register file lives in
`aes_base` so a map change lands in one header. Cipher work is OpenSSL
EVP, not an inlined AES round function.

[source,cpp]
----
class aes_model : public aes_base
----

----
aes_model          cipher FSM, alerts, KM sideload, quantum keeper   (aes.*)
  └─ aes_base      regmodel::Memory + software-visible words              (aes_base.*)
       └─ aes_register.h   RO/WO/RW types
----

====== Threads and sockets

Cipher, clear, and PRNG-reseed work is `sc_spawn`'d so a TLM write can
return while the engine waits. Alert and idle pins are driven from
dedicated methods so reset is not a second SystemC writer.

`sep-vp` binds the TLM register target at the TRM AES aperture and the
key-manager destination socket. There is no interrupt pin on this model.

[cols="32%,28%,40%",options="header"]
|===
|Port |Type |Platform bind
|`aes_base` memory target |TLM 32-bit |`sep-vp` SimpleBus, AES window
|`keymgr_tl_socket` |TLM 32-bit target |KM AES key socket
|`clk_i` |`sc_in<bool>` |Presence only; delay uses `m_clk_freq_hz`
|`rst_ni` |`sc_in<bool>` |Active-low; falling edge clears state
|`lc_escalate_en` |`sc_in<bool>` |Life-cycle escalate; fatal lock
|`idle_o` |`sc_out<bool>` |High while the cipher FSM is idle
|`alert_recov_ctrl_update_err` |`sc_out<bool>` |Shadowed-CTRL mismatch
|`alert_fatal_fault` |`sc_out<bool>` |Fatal fault / escalate lock
|===

CTRL writes latch mode, operation, and key length. DATA_IN completion
auto-starts unless manual mode is set; TRIGGER then starts, clears, or
reseeds. Key shares XOR to the OpenSSL key. Sideload loads the KM push
buffers when that path is enabled.

`sanitise_ctrl_shadowed()` is the single point where illegal CTRL_SHADOWED
encodings are mapped to their defaults, and it runs *before* the value is
staged into the shadow register. Every downstream consumer — cipher
selection, latency, PRNG reseed threshold — therefore only ever sees a
legal encoding; their `switch` statements stay exhaustive over the enum so
that adding a mode or key length is a `-Wswitch` build failure rather than
a silent fallthrough, but their `default:` arms are unreachable and marked
as such.

The key-manager sideload socket is modelled as zero latency: the incoming
annotated `delay` is passed through untouched rather than cleared, so a
temporally decoupled key manager keeps the local-time offset it arrived
with.

----
  TLM MMIO ──► aes_base::memory ──► sc_spawn perform_cipher_operation
                                 └► sc_spawn clear / PRNG reseed
                                           │
                                           ▼
                                    OpenSSL EVP
                                           │
  keymgr_tl_socket ──► XOR reconstruct ──► key shares
                                           │
                      update_alert_outputs ──► alert_*
                      update_idle_status   ──► idle_o
----

GCM is driven a block at a time through `CTRL_GCM_SHADOWED.PHASE`
(INIT / RESTORE / AAD / TEXT / SAVE / TAG) with the GHASH accumulator
carried across phases, rather than as a single cipher call. The model
keeps no length counters, matching the hardware.

====== CCI parameters

Knobs are `regmodel::Param` and are re-read when used. Block latency is
charged through `tlm_quantumkeeper::inc()` using `m_clk_freq_hz`
(hardcoded default `1e8`; not a CCI parameter despite the HLD).

[cols="36%,20%,44%",options="header"]
|===
|Parameter |Default |Use
|`verbosity` |2 (Release: 1) |regmodel log level
|===

====== Modeling gaps versus RTL

* No cycle-accurate rounds, S-boxes, or DOM masked datapath.
* Unmasked LT delay only; masked RTL latency is not modeled.
* `clk_i` is a boolean; frequency does not come from the pin.
* No EDN / `entropy_src` ports; reseeds call OpenSSL `RAND_bytes()`.
* First-order masking is share storage plus XOR, not a masked circuit.
* No interrupt outputs (the RTL block has none either).
