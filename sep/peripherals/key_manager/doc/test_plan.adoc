[[key-manager-test-plan]]
===== Test Plan

====== Standalone bench

`key_manager_testbench` (`test/inc/testbench.h`) is a TLM
initiator into `mailbox_socket`, recording stubs on the eight
DEST sockets, plus `clk`-less `rst_ni` / `wipe_ni` / `irq`.
Command helpers build CRC-8 / CRC-32C frames.

Success: every check in the 14 func files passes; `--asan`
produces no `asan.log.*`; line coverage on the touched model
sources meets the repository ≥ 95% gate.

How to run (from `sep/peripherals/key_manager`):

[source,bash]
----
./run_tests.sh              # Release build + run
./run_tests.sh --debug
./run_tests.sh --asan       # ASan + UBSan
./run_tests.sh --coverage   # isolated build/coverage; do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --docs
./run_tests.sh --cppcheck
./run_tests.sh --clean

# All SEP peripherals, this IP included:
cd sep/peripherals
./run_all_peripherals.sh
./run_all_peripherals.sh --clean key_manager
----

`run_tests.sh` loads `SYSTEMC_HOME` / `CCI_HOME` through
`sep/peripherals/setup_build_env.sh`. Set those in
`vp/configure_vp.sh` or export them first.

====== Platform firmware tests

These run on `sep-vp` with a RISC-V bare-metal toolchain. Build
the VP first (`make sep-vp` from the repo root after
`vp/configure_vp.sh`).

[source,bash]
----
cd sw/sep-vp-tests/fw-tests-from-tt-oca-hw/fw/sep
./run_test.sh sep_abr_km_seed_test
./run_test.sh kmac_key_sideload_test
./run_all_tests.sh            # full firmware suite, includes the above

# Standalone mailbox exerciser (not the fw-tests tree):
cd sw/sep-vp-tests/sep-keymgr-test
make
----

`sep_abr_km_seed_test` uses DEST bit 4 into Adams Bridge.
`sep_km_efuse_coexist_test` needs a KM CPU the model does not
have.
