[[sep-cpu-ctrl-test-plan]]
===== Test Plan

====== Standalone bench

`sep_cpu_ctrl_test` (`test/sep_cpu_ctrl_test.cpp`) is a TLM initiator
into the CSR aperture plus `rst_ni` and the window / NMI outputs.
It pokes `hwif_in` directly for fuse-sense, straps, and timeout bits.

Success: every `[PASS] T*` line holds; `--asan` produces no
`asan.log.*`; line coverage on the touched model sources meets the
repository ≥ 95% gate.

How to run (from `sep/peripherals/sep_cpu_ctrl`):

[source,bash]
----
./run_tests.sh              # Release build + run
./run_tests.sh --debug
./run_tests.sh --asan       # ASan + UBSan
./run_tests.sh --coverage   # isolated build/coverage; do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

# All SEP peripherals, this IP included:
cd sep/peripherals
./run_all_peripherals.sh
./run_all_peripherals.sh --clean sep_cpu_ctrl
----

`run_tests.sh` loads `SYSTEMC_HOME` / `CCI_HOME` through
`sep/peripherals/setup_build_env.sh`. Set those in `vp/configure_vp.sh`
or export them first.

|===
