[[csrng]]
==== CSRNG

The hardware contract (aperture, CSRs, CTR_DRBG commands, GENBITS,
interrupts) is in the hardware TRM. This directory documents the
SystemC/TLM-2.0 model (`csrng_model`) and how to test it.
