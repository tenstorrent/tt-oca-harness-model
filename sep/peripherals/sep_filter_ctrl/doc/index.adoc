[[sep-filter-ctrl]]
==== SEP Filter Control

The hardware contract (filter table, BlockByDefault, `filter_skip_i`)
is in the hardware TRM. This directory documents the SystemC/TLM-2.0
model (`sep_filter_ctrl_ip`) and how to test it. One class, two
`sep-vp` instances (outbound 32 entries, inbound 16).
