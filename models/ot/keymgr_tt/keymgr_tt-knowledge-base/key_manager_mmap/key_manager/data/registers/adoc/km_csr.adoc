.SCRAMBLER_CTRL Register
|===
| Bits | Field | Access | Reset | Description
| 31:2 | `rsvd` | R | 0x0 a| Reserved
| 1 | `lock` | RW | 0x0 a| Lock scrambler key and enable bit. Once set, key and enable cannot be modified until reset. Write-once (0->1 only). Security requirement: prevents disabling scrambling after key provisioning.
| 0 | `enable` | RW | 0x0 a| Enable SRAM scrambling. When 0, data passes through unmodified. Locked when LOCK=1 (security requirement).
|===
