[[uart-test-plan]]
===== Test Plan

====== Standalone bench

`uart_tb` (`test/uart_tb.cpp`) is a TLM initiator into the register
window plus `rst_n_i`, modem pins, and `inject_rx_char` / `dbg_tx_pop`
/ `dbg_reg` helpers. No serial line is required.

Success: the bench prints `ALL TESTS PASSED`; `--asan` produces no
`asan.log.*`.

How to run (from `smc/peripherals/uart`):

[source,bash]
----
./run_tests.sh              # Release build + run
./run_tests.sh --ctest
./run_tests.sh --asan
./run_tests.sh --coverage   # isolated build_cov/; do not combine with --asan
./run_tests.sh --clean

cd smc
./run_all_smc_tests.sh uart
----

`run_tests.sh` probes `SYSTEMC_HOME` / `CCI_HOME`. A local `deps.env`
overrides those paths.
