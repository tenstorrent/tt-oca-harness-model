[[pvt-wrap-test-plan]]
===== Test Plan

====== Standalone bench

`test/pvt_wrap_tb.cpp` is a TLM initiator plus the observation /
voltage / interrupt pins. It enables channels, waits for the tick to
validate the process counter, and checks TLM error paths.

Success: the bench prints `ALL TESTS PASSED`; `--asan` produces no
`asan.log.*`; line coverage on the touched model sources meets the
repository ≥ 95% gate.

How to run (from `smc/peripherals/pvt_wrap`):

[source,bash]
----
./run_tests.sh
./run_tests.sh --asan
./run_tests.sh --coverage   # do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

cd smc
./run_all_smc_tests.sh pvt_wrap
----

`run_tests.sh` probes `SYSTEMC_HOME` / `CCI_HOME` or reads `deps.env`.
