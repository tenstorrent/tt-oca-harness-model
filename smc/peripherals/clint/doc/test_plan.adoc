[[clint-test-plan]]
===== Test Plan

====== Standalone bench

`test/clint_tb.cpp` is a TLM initiator plus `msip_o` / `mtip_o` /
`rst_n_i`. Auto-tick is disabled so time is advanced with
`dbg_set_mtime()`. `test/clint_tick_tb.cpp` is a second bench that
leaves auto-tick on and checks `mtime` advance, reset re-arm, and
automatic `mtip_o`.

Success: both benches print `ALL TESTS PASSED`; `--asan` produces no
`asan.log.*`; line coverage on the touched model sources meets the
repository ≥ 95% gate.

How to run (from `smc/peripherals/clint`):

[source,bash]
----
./run_tests.sh              # Release build + run
./run_tests.sh --asan
./run_tests.sh --coverage   # do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

cd smc
./run_all_smc_tests.sh clint
----

`run_tests.sh` probes `SYSTEMC_HOME` / `CCI_HOME` or reads `deps.env`.
