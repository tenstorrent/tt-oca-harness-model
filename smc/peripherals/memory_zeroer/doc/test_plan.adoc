[[memory-zeroer-test-plan]]
===== Test Plan

====== Standalone bench

`test/memory_zeroer_tb.cpp` is a TLM register initiator plus a
simple memory target on `dma_socket`. It programs DEST/SIZE, starts
jobs, checks zero-fill and IRQ gating, and injects a failing DMA
target.

Success: the bench prints `ALL TESTS PASSED`; `--asan` produces no
`asan.log.*`; line coverage on the touched model sources meets the
repository ≥ 95% gate.

How to run (from `smc/peripherals/memory_zeroer`):

[source,bash]
----
./run_tests.sh
./run_tests.sh --asan
./run_tests.sh --coverage   # do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

cd smc
./run_all_smc_tests.sh memory_zeroer
----

`run_tests.sh` probes `SYSTEMC_HOME` / `CCI_HOME` or reads `deps.env`.
