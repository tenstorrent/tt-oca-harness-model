[[beu-test-plan]]
===== Test Plan

====== Standalone bench

`test/beu_tb.cpp` is a TLM initiator plus `inject_error()`.
`test/beu_neg_tb.cpp` covers TLM error codes, RO writes, and gated
injection.

Success: both benches print `ALL TESTS PASSED`; `--asan` produces no
`asan.log.*`; line coverage on the touched model sources meets the
repository ≥ 95% gate.

How to run (from `smc/peripherals/beu`):

[source,bash]
----
./run_tests.sh
./run_tests.sh --asan
./run_tests.sh --coverage   # do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

cd smc
./run_all_smc_tests.sh beu
----

`run_tests.sh` probes `SYSTEMC_HOME` / `CCI_HOME` or reads `deps.env`.

====== Platform firmware tests

These run on `smc-vp` with a RISC-V bare-metal toolchain. Build the
VP first (`make smc-vp` from the repo root after `vp/configure_vp.sh`).

[source,bash]
----
cd sw/smc-vp-tests
./run_smc_vp_tests.sh smc-beu-test
./run_smc_vp_tests.sh smc-beu-error-test
----

`smc-beu-test` is register smoke across the four per-core windows.
`smc-beu-error-test` opts into `beu_inject*` in its `.ini` and checks
accrual, software ack, and per-core isolation. The numbered Markdown
`doc/04_BEU_Platform_Integration_Test_Plan.md` is the historical
integration checklist; do not treat it as a second CSR spec.
