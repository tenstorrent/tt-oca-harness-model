[[reset-unit]]
==== Reset Unit

The hardware contract (reset derivation, per-subsystem bundles, FLR
cool-reset, isolate CSRs) is in the hardware TRM. This directory
documents the SystemC/TLM-2.0 model (`smc::reset_unit`) and how to test
it.
