[[reset-unit-test-plan]]
===== Test Plan

====== Standalone bench

`reset_unit_tb` and `reset_unit_neg_tb` (`test/`). The primary bench
drives every input pin, `set_jtag_ctrl()`, and the register target.
The negative bench probes constructor fatals without `sc_start`.

Success: both benches print `ALL TESTS PASSED`; CTest reports 2/2;
`--asan` produces no `asan.log.*`.

How to run (from `smc/peripherals/reset_unit`):

[source,bash]
----
./run_tests.sh              # Release build + run both benches
./run_tests.sh --ctest
./run_tests.sh --asan
./run_tests.sh --coverage   # isolated build_cov/; do not combine with --asan
./run_tests.sh --clean

cd smc
./run_all_smc_tests.sh reset_unit
----

`run_tests.sh` probes `SYSTEMC_HOME` / `CCI_HOME`.
