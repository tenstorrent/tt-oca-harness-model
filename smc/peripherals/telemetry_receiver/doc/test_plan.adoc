[[telemetry-receiver-test-plan]]
===== Test Plan

====== Standalone bench

`test/telemetry_receiver_tb.cpp` injects beats through
`telemetry_encode_message()` / `push_atb_beats()` and programs the
register aperture. `test/telemetry_receiver_neg_tb.cpp` covers TLM
errors, empty-queue pop, flush precedence, threshold truncation, and
the 32-counter geometry.

Success: both benches print `ALL TESTS PASSED`; `--asan` produces no
`asan.log.*`; line coverage on the touched model sources meets the
repository ≥ 95% gate.

How to run (from `smc/peripherals/telemetry_receiver`):

[source,bash]
----
./run_tests.sh
./run_tests.sh --asan
./run_tests.sh --coverage   # do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

cd smc
./run_all_smc_tests.sh telemetry_receiver
----

`run_tests.sh` probes `SYSTEMC_HOME` / `CCI_HOME` or reads `deps.env`.
