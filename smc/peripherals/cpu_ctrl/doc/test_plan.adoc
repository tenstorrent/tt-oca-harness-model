[[cpu-ctrl-test-plan]]
===== Test Plan

====== Standalone bench

`test/cpu_ctrl_tb.cpp` is a TLM initiator into the register window,
plus WDT sticky inputs and the debug back-doors (`set_scratch`,
`set_wb_pc`, `dbg_wdt_stage2_tick`).

Success: the bench prints `ALL TESTS PASSED`; `--asan` produces no
`asan.log.*`; line coverage on the touched model sources meets the
repository ≥ 95% gate.

How to run (from `smc/peripherals/cpu_ctrl`):

[source,bash]
----
./run_tests.sh
./run_tests.sh --asan
./run_tests.sh --coverage   # do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

cd smc
./run_all_smc_tests.sh cpu_ctrl
----

`run_tests.sh` probes `SYSTEMC_HOME` / `CCI_HOME` or reads `deps.env`.

the PeakRDL window to `cluster.ctrl`, not this standalone model's
