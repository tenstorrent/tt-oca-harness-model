[[avsbus-controller-test-plan]]
===== Test Plan

====== Standalone bench

`test/avsbus_controller_tb.cpp` covers the happy path: reset,
register R/W, command/response, IRQ mask/clear, FIFO overflow and
underflow, max retries, forced resync, and CCI.
`test/avsbus_controller_neg_tb.cpp` covers TLM errors, RO/WO,
back-pressure, ACK flavours, canned READ responses, CRC-3, and a
constructor guard on zero FIFO depth.

Success: both benches print `ALL TESTS PASSED`; `--asan` produces no
`asan.log.*`; line coverage on the touched model sources meets the
repository ≥ 95% gate.

How to run (from `smc/peripherals/avsbus_controller`):

[source,bash]
----
./run_tests.sh
./run_tests.sh --asan
./run_tests.sh --coverage   # do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

cd smc
./run_all_smc_tests.sh avsbus_controller
----

`run_tests.sh` probes `SYSTEMC_HOME` / `CCI_HOME` or reads `deps.env`.
