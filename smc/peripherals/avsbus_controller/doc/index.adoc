[[avsbus-controller]]
==== AVSBus Controller

The hardware contract (AVSBus 1.3.1 frames, CSRs, interrupt bits) is
in the hardware TRM. This directory documents the SystemC/TLM-2.0
model (`smc::avsbus_controller`) and how to test it.
