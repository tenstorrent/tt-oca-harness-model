[[octs-system-timer-test-plan]]
===== Test Plan

====== Standalone bench

`test/octs_system_timer_tb.cpp` instantiates three DUTs on one
`sc_clock`: a PRIMARY, a SECONDARY wired to it (end-to-end protocol),
and a standalone SECONDARY whose sync inputs the bench drives.
Stimulus runs on the falling edge so cycle counts are exact.

Success: the bench prints `ALL TESTS PASSED` with every `CHECK_EQ`
green; `--asan` produces no `asan.log.*`; line coverage on the
touched model sources meets the repository ≥ 95% gate.

How to run (from `smc/peripherals/octs_system_timer`):

[source,bash]
----
./run_tests.sh
./run_tests.sh --asan
./run_tests.sh --coverage   # do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

cd smc
./run_all_smc_tests.sh octs_system_timer
----

`run_tests.sh` probes `SYSTEMC_HOME` / `CCI_HOME` or reads `deps.env`.

|===

====== Platform firmware tests

Build `smc-vp` first. The secondary test uses its own `.ini` to
strap `dut.octs_is_primary=false`. End-to-end PRIMARY→SECONDARY sync
is unit-test only (`smc-vp` has one timer).

[source,bash]
----
cd sw/smc-vp-tests
./run_smc_vp_tests.sh smc-octs-timer-test
./run_smc_vp_tests.sh smc-octs-timer-secondary-test
----
