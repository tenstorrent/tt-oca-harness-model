[[plic-test-plan]]
===== Test Plan

====== Standalone bench

`test/plic_tb.cpp` is a TLM initiator into the register aperture plus
`src_in` / `ctx_out` / `rst_n_i` drivers. It uses the debug back-door
(`dbg_priority`, `dbg_pending`, `dbg_claim_top`, `dump_state`) so
CLAIM side-effects can be checked without going through the bus.

Success: the bench prints `ALL TESTS PASSED`; `--asan` produces no
`asan.log.*`; line coverage on the touched model sources meets the
repository ≥ 95% gate.

How to run (from `smc/peripherals/plic`):

[source,bash]
----
./run_tests.sh              # Release build + run
./run_tests.sh --asan       # ASan + UBSan
./run_tests.sh --coverage   # isolated build; do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

# All SMC IPs, this one included:
cd smc
./run_all_smc_tests.sh plic
----

`run_tests.sh` probes `SYSTEMC_HOME` / `CCI_HOME` or reads `deps.env`.
Set those in `vp/configure_vp.sh` or export them first.

====== Platform firmware tests

There is no `smc-plic-test` in `sw/smc-vp-tests/`. PLIC on `smc-vp` is
covered indirectly by firmware tests that take an aggregated peripheral
interrupt (for example `smc-beu-test`). Standalone coverage is
`./run_tests.sh` in this directory.
