[[smc-vp-implementation]]
=== SystemC/TLM-2.0 Implementation

`smc-vp` (`vp/platform/smc/`) wires `smc_fabric`, the modeled
peripherals, and a Whisper-backed RV64 cluster. Firmware sees the
local-alias aperture. Bases must match the TRM RDL and xbar packages;
where `smc_platform.cpp` still disagrees, treat that as a modeling
bug, not a second spec. Bases live in `smc_common.h` / `smc_platform.cpp`
and must match the TRM RDL and xbar packages.

==== Platform pieces

[cols="28%,36%,36%",options="header"]
|===
|Role |Tree |Notes
|CPU cluster |`smc/cpu_cluster` |Whisper ISS, 1–4 harts
|Fabric |`smc/smc_fabric` |TLM router, remap, filter sockets
|Modeled IPs |`smc/peripherals/*` |WDT, reset, DMA, UART, I2C, I3C, OCTS, telemetry, PLIC, CLINT, BEU, PLL, PVT, …
|Unmodeled RDL slots |stub targets in `smc_platform.cpp` |Mailbox, GPIO, eFuse, DTP, DFX, misc_wrap
|Wiring |`vp/platform/smc/` |CCI INI
|===

Every modeled IP has the three-page set under
`smc/peripherals/<ip>/doc/` (`index.adoc`, `implementation.adoc`,
`test_plan.adoc`).
The fabric, CPU cluster, and AOU use the same layout in
`smc/smc_fabric/doc/`, `smc/cpu_cluster/doc/`, and `aou/doc/`.

Existing integration notes in this directory
(`systemc_tlm2_integration_guide.adoc`,
`platform_test_and_firmware_guide.adoc`) stay as working notes. New
text uses `implementation.adoc` / `test_plan.adoc` only.
