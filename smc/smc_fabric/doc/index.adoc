[[smc-fabric]]
==== SMC Fabric

The hardware contract (AXI fabric topology, alias/output remap, filter
CSRs, local xbar decode) is in the hardware TRM. This directory
documents the SystemC/TLM-2.0 model (`smc::smc_fabric`) and how to
test it.
