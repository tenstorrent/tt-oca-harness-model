[[smc-fabric-test-plan]]
===== Test Plan

====== Standalone bench

`test/smc_fabric_tb.cpp` binds the six target sockets to probe
initiators and the initiator sockets to stub targets. It covers reset
defaults, local decode, alias/output remap, inbound/outbound filters,
DMI denial, and CSR read-back.

Success: the bench prints `ALL TESTS PASSED`; `--asan` produces no
`asan.log.*`; line coverage on `smc_fabric.cpp` meets the repository
≥ 95% gate.

How to run (from `smc/smc_fabric`):

[source,bash]
----
./run_tests.sh
./run_tests.sh --asan
./run_tests.sh --coverage   # do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

cd smc
./run_all_smc_tests.sh smc_fabric
----

`run_tests.sh` probes `SYSTEMC_HOME` / `CCI_HOME` or reads `deps.env`.
