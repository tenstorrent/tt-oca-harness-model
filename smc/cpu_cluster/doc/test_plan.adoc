[[smc-cpu-cluster-test-plan]]
===== Test Plan

====== Standalone bench

`test/cluster_tb.cpp` is a self-checking binary. It constructs the
cluster, binds stub memories and IRQ wires, and links the PLIC model
for the CPU→PLIC→CPU case. CLINT is wire-stubbed.

Success: the bench prints `ALL TESTS PASSED`; `--asan` produces no
`asan.log.*`; line coverage on `src/` meets the repository ≥ 95% gate.

How to run (from `smc/cpu_cluster`):

[source,bash]
----
cp deps.env.example deps.env   # first time; set SYSTEMC_HOME / CCI_HOME / Whisper
./run_tests.sh
./run_tests.sh --asan
./run_tests.sh --coverage   # do not combine with --asan
./run_tests.sh --ctest
./run_tests.sh --clean

cd smc
./run_all_smc_tests.sh cpu_cluster
----
